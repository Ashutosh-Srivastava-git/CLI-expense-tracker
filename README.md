# CLI Personal Expense Tracker

## What It Does

- Add expenses =  enter an amount, pick a category. Data is saved to a local JSON file.
- View all expenses =  a table with date, category, amount, and note.
- Filter by category =  view a specific category and its subtotal.

## How to run
 Make sure you have python 3.8 installed.
 Open Terminal and type in :
 python CLI_expense_tracker.py
